# COCKTAIL EMBASSY

Барное стекло ручной выдувки для баров и ресторанов. Дубай, доставка по ОАЭ и миру.
Telegram Mini App + бот + сайт в одном процессе: витрина, каталог, корзина, заказы,
инвойс на компанию с VAT 5 %, чат поддержки и админ-панель в боте. Два языка — **RU / EN**.

> Механика повторяет проверенный продукт «Посудная лавка», но полностью переделана под
> COCKTAIL EMBASSY: валюта AED (USD — справочно), доставка по Дубаю/эмиратам/экспорт/самовывоз,
> счёт для компании с TRN, налог VAT 5 %, бренд, тексты и цены из прайса бренда,
> фотографии — из прайса и сгенерированные студийные рендеры.

## Что внутри

**Витрина (Mini App)** — тёмный интерфейс в стиле нативного Telegram, safe-area, таб-бар,
нативные `MainButton`/`BackButton`, хаптик:

- главная: hero, коллекции, «все позиции», хиты и новинки;
- каталог: поиск, сортировки (популярные, дешевле, дороже, по объёму, по названию), фильтры
  «только новинки», «в наличии», «до суммы», чипсы коллекций;
- карточка товара: галерея, характеристики (объём, высота, диаметр, материал, гравировка),
  похожие позиции, добавление в корзину;
- корзина: прогресс до бесплатной доставки, шаг количества, сумма USD справочно;
- оформление: доставка (Дубай / эмираты / экспорт / самовывоз), контакты, для счёта — название
  компании, TRN, адрес, e-mail бухгалтерии, комментарий, согласие;
- заказы: список, статусы, детали, повтор, отмена, ожидание оплаты;
- избранное, кабинет, доставка и оплата, о бренде, чат поддержки с быстрыми вопросами.

**Бот (Telegram)** — витрина в чате: коллекции → позиции → карточка товара с фото,
«спросить об этой позиции» (вопрос уходит в поддержку с артикулом), доставка и оплата,
язык RU/EN, уведомления администраторам о новых заказах и сообщениях.

**Админ-панель в боте** (`/admin`) — заказы (фильтры по статусам, поиск по номеру, смена
статуса, отметка оплаты, счёт на печать), поддержка (списки тредов, ответы, инициативные
сообщения), каталог (пагинация, карточка позиции, цена AED и USD, названия и описания RU+EN,
объём, сток, скрытие, хит/новинка, удаление и возврат, добавление позиции, **загрузка фото**),
коллекции (создание, переименование RU/EN, удаление), магазин и контакты, реквизиты для
инвойсов (TRN, лицензия, банк, IBAN, SWIFT), статистика (заказы, выручка, средний чек, топ
позиций), рассылка, настройки и диагностика.

**Счёт и оплата.** Заказ можно оформить двумя способами: счёт на компанию (формируется
`CE-2026-0001`, VAT 5 %, сумма прописью RU/EN, печать в PDF по ссылке с ключом) или карта
онлайн (ссылка от менеджера; онлайн-эквайринг подключается переменными окружения).

## Быстрый старт

```bash
npm install
cp .env.example .env      # заполнить BOT_TOKEN, ADMIN_IDS, PUBLIC_URL
npm start                 # MODE=all: витрина + бот в одном процессе
```

Проверить без бота:

```bash
MODE=web npm start        # только сайт: http://localhost:3000
curl localhost:3000/health
```

Node 20+. Зависимости только `express` и `grammy` — ставится и запускается на любом
хостинге Node, база не нужна: данные лежат в `data/db.json`.

### Переменные окружения

Всё опциональное перечислено в `.env.example`. Ключевые:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN`, `ADMIN_IDS`, `BOT_USERNAME` | бот и доступ в админ-панель |
| `PUBLIC_URL` | адрес приложения: ссылки на инвойсы, кнопка Mini App, вебхук |
| `MODE` | `all` \| `web` \| `bot` |
| `PORT`, `EXTRA_PORTS`, `HOST` | порты (можно слушать несколько сразу) |
| `DEFAULT_LOCALE` | `ru` или `en` — язык по умолчанию |
| `SHIPPING_COST`, `FREE_SHIPPING_FROM`, `WHOLESALE_FROM` | доставка и опт, AED |
| `SELLER_*`, `VAT_RATE`, `INVOICE_PREFIX` | реквизиты и нумерация инвойсов |
| `PAYMENT_LINK`, `PAYMENT_NOTE`, `YOOKASSA_*` | онлайн-оплата картой |
| `TELEGRAM_MODE` | `polling` (по умолчанию) или `webhook` |

Реквизиты, контакты, тексты и цены доставки можно менять **без перезапуска** — прямо
в админ-панели бота (разделы «Магазин и контакты», «Реквизиты», «Настройки»).

## Каталог и фотографии

Источник данных — прайс бренда (Google-таблица и её PDF-экспорт). В репозитории он уже
разложен в машинный вид:

```
data/price-list.json   # 25 позиций: артикул, название RU/EN, коллекция, объём, цена AED/USD
data/catalog.json      # то же + фото, характеристики, признаки «скоро», категории с описаниями
```

Пересобрать каталог из прайса:

```bash
npm run catalog                          # data/price-list.json -> data/catalog.json
npm run photos -- "COCKTAIL EMBASSY.pdf" # вырезать фото позиций из PDF в webapp/assets/products
```

Товарные фото — **из прайса бренда**, ничего не дорисовывается. Если позиция «SOON», в
прайсе может стоять общее изображение: фото любой позиции можно заменить в боте
(карточка позиции → «🖼 Фото» → отправить фото сообщением).

## Структура

```
src/
  index.js          запуск по MODE (web/bot/all), самовосстановление витрины
  config.js         переменные окружения, бренд, валюта, реквизиты, оплата
  store.js          JSON-хранилище с атомарной записью
  i18n.js           словари RU/EN (витрина и бот), склонения, интерполяция
  catalog.js        каталог: базовый прайс + правки админа, CRUD, фото, коллекции
  orders.js         заказы: доставка, VAT, статусы, события
  payments/         инвойс (HTML для печати) и ЮKassa
  support.js        чаты поддержки
  server.js         express: API, статика Mini App, SPA-фолбэк, инвойс, вебхук
  bot/index.js      бот: витрина в чате, поддержка, уведомления
  bot/admin.js      админ-панель в боте
  bot/format.js     форматирование сообщений
webapp/             Telegram Mini App (ванильный ES-модульный фронтенд, без сборки)
  index.html, css/, js/{i18n,api,state,router,ui,icons,components,app}.js, js/views/*
  assets/products/  фото позиций   assets/brand/  логотип и иконки
scripts/            извлечение фото из PDF и сборка каталога
data/               прайс, каталог, база заказов (db.json создаётся сам)
```

## API (кратко)

`GET /api/config` · `GET /api/catalog` · `GET|POST /api/favorites[/:id]` ·
`GET|PUT /api/cart` · `POST /api/cart/quote` · `GET|POST /api/orders` ·
`GET /api/orders/:id` · `POST /api/orders/:id/check|cancel` ·
`GET|POST /api/support` · `GET /api/support/updates` · `GET /invoice/:id?k=…` ·
`POST /webhook/yookassa` · `GET /health`

Язык запроса: `?lang=ru|en` → cookie → `language_code` из Telegram → `Accept-Language`.
Авторизация гостя — подписанная cookie, Telegram — проверка `initData` по HMAC.
